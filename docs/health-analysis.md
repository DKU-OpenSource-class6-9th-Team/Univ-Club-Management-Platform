# Health Analysis

이 문서는 **Club Management Platform** 프로젝트의 동아리 건강도 분석 기능을 설명합니다.

건강도 분석은 동아리의 회원 활동, 일정 운영, 회비 관리, 만족도 데이터를 기반으로 동아리 운영 상태를 점수화하고, 주요 강점과 보완점을 안내하는 기능입니다.

---

## 1. 건강도 분석 목적

동아리 운영은 단순히 회원 수가 많다고 해서 안정적이라고 판단하기 어렵습니다.
따라서 이 프로젝트에서는 다음과 같은 운영 데이터를 종합하여 동아리 건강도를 분석합니다.

* 회원 활동성
* 활동/일정 운영성
* 재정 운영 투명성
* 만족도 및 응답률
* 동아리별 지표 비교 Notice
* 최종 평가 코멘트
* 건강도 랭킹

건강도 분석의 목적은 운영진이 현재 동아리의 상태를 빠르게 파악하고, 개선이 필요한 지표를 확인할 수 있도록 돕는 것입니다.

---

## 2. 전체 건강도 점수

전체 건강도 점수는 여러 영역별 점수를 종합하여 계산합니다.

현재 전체 건강도는 다음 세 영역을 기준으로 합니다.

| 영역            | 가중치 |
| ----------------|  --:   |
| 회원 활동성      |  30%   |
| 활동/일정 운영성 |  30%   |
| 재정 운영 투명성 |  40%   |

계산식은 다음과 같습니다.

```txt
전체 건강도 점수 =
(회원 활동성 점수 × 0.30 + 활동/일정 운영성 점수 × 0.30 + 재정 운영 투명성 점수 × 0.40)
÷ 사용 가능한 가중치 합
```

 **데이터가 없는 영역을 0점 처리하지 않는다**

예를 들어 회비 데이터가 아직 없다면 재정 운영 투명성 영역은 전체 점수 계산에서 제외되고, 준비된 영역만 기준으로 점수가 계산됩니다.

---

## 3. 건강도 상태 기준

점수에 따라 화면에 표시되는 상태는 다음 기준을 따릅니다.

|  점수 범위 | 상태    |
|   -----:   |  -----  |
| 90점 이상  | 매우 우수|
| 70점 이상  | 양호     |
| 50점 이상  | 보통     |
| 50점 미만  | 주의     |

이 상태값은 전체 건강도뿐만 아니라 각 영역별 점수에도 사용됩니다.

---

## 4. 회원 활동성

회원 활동성은 동아리 회원의 활동 상태와 활동 점수를 기반으로 계산합니다.

### 사용 데이터

```txt
- club_members_clubmembership
- 회원 상태(status)
- 회원 활동 점수(activity_score)
```

### 주요 지표

| 지표          | 설명                                          |
| ------------- | ----------------------------------------------|
| 활동 회원 비율 | 전체 회원 중 활동 상태 회원 비율                |
| 평균 활동 점수 | 회원들의 activity_score 평균                   |
| 활동 회원 수   | 활동 중인 회원 수                              |
| 비활동 회원 수 | 휴면, 탈퇴, 제한 등 운영상 주의가 필요한 회원 수 |

### 계산 방식

```txt
회원 활동성 점수 =
활동 회원 비율 × 0.8 + 평균 활동 점수 × 0.2
```
---

## 5. 활동/일정 운영성

활동/일정 운영성은 일정 만족도와 실제 일정 운영 데이터를 함께 반영합니다.

### 사용 데이터

```txt
- Event
- EventApplication
- Attendance
- ClubMembership
- 만족도 조사 중 활동/일정 만족도
```

### 주요 지표

| 지표                   | 설명                                          |
| ---------------------- | --------------------------------------------- |
| 활동/일정 만족도        | 만족도 조사에서 수집된 일정 관련 평균 점수        |
| 일정 활동 인원 비율     | 전체 활동 회원 중 일정에 1회 이상 참여한 회원 비율 |
| 신청자 대비 실제 출석률  | 일정 신청자 중 실제 출석 또는 지각 처리된 비율    |
| 일정 운영 안정성        | 완료/취소 일정 중 완료된 일정 비율                |

### 계산 방식

기본 계산식은 다음과 같습니다.

```txt
활동/일정 운영성 점수 =
활동/일정 만족도 점수 × 0.35
+ 일정 활동 인원 비율 점수 × 0.35
+ 신청자 대비 실제 출석률 × 0.20
+ 일정 운영 안정성 × 0.10
```

다만 일부 데이터가 없는 경우에는 준비된 데이터만 기준으로 점수를 계산합니다.

예를 들어 만족도 데이터는 없지만 일정 출석 데이터가 있다면, 일정 운영 데이터만 기준으로 점수가 산정됩니다.

---

## 6. 일정 활동 인원 비율 기준

일정 활동 인원 비율은 전체 활동 회원 중 일정에 1회 이상 실제 참여한 회원의 비율입니다.

현재 기준에서는 전체 활동 회원 중 **80% 이상이 일정에 1회 이상 참여하면 만점**으로 봅니다.

```txt
일정 활동 인원 비율 점수 =
min((일정 활동 인원 비율 / 80) × 100, 100)
```

예를 들어 일정 활동 인원 비율이 80% 이상이면 100점이고, 그보다 낮으면 비율에 따라 점진적으로 감점됩니다.

---

## 7. 재정 운영 투명성

재정 운영 투명성은 회비 납부 현황, 수입/지출 내역, 증빙자료 첨부 여부, 회비 사용 만족도를 기반으로 계산합니다.

### 사용 데이터

```txt
- MemberFeePayment
- FeeTransaction
- FeeReceipt
- 회비 사용 만족도
```

### 주요 지표

| 지표           | 설명                                   |
| -------------- | -------------------------------------- |
| 회비 납부율     | 전체 회비 납부 대상 중 납부 완료 비율     |
| 미납률          | 전체 회비 납부 대상 중 미납 비율         |
| 증빙자료 첨부율  | 수입/지출 거래 중 증빙자료가 첨부된 비율  |
| 회비 사용 만족도 | 만족도 조사에서 수집된 회비 관련 평균 점수 |
| 총수입          | 회비 수입 합계                           |
| 총지출          | 회비 지출 합계                           |
| 잔액            | 총수입 - 총지출                          |

### 회비 만족도 데이터가 있는 경우

```txt
재정 운영 투명성 점수 =
회비 납부율 × 0.20
+ 증빙자료 첨부율 × 0.40
+ 회비 사용 만족도 점수 × 0.40
```

### 회비 만족도 데이터가 없는 경우

```txt
재정 운영 투명성 점수 =
회비 납부율 × 0.3333
+ 증빙자료 첨부율 × 0.6667
```

즉, 회비 만족도 데이터가 없는 경우에도 회비 납부율과 증빙자료 첨부율을 기준으로 재정 운영 투명성을 부분적으로 계산합니다.

---

## 8. 만족도 분석

만족도 분석은 활동/일정 만족도와 회비 사용 만족도를 계산하는 데 사용됩니다.

### 사용 데이터

```txt
- SurveyItem
- SurveySubmission
- SurveyState
```

### 주요 지표

| 지표                | 설명                           |
| ------------------- | -------------------------------|
| 활동/일정 만족도 평균 | 일정 관련 만족도 응답 평균       |
| 회비 사용 만족도 평균 | 회비 관련 만족도 응답 평균       |
| 전체 만족도 평균      | 일정/회비 만족도 전체 평균       |
| 응답률               | 만족도 조사 대상자 중 제출자 비율 |

만족도 점수는 1~5점 평균을 100점 만점으로 환산합니다.

```txt
만족도 점수 = (5점 만점 평균 / 5) × 100
```

예를 들어 평균 만족도가 4.0점이면 80점으로 환산됩니다.

응답률은 건강도 점수 계산에 직접 섞기보다는, Notice 비교와 참고 지표로 활용됩니다.

---

## 9. 동아리별 지표 비교 Notice

동아리별 지표 비교 Notice는 현재 동아리의 세부 지표가 비교 기준에 비해 높은지 낮은지를 안내하는 기능입니다.

이 Notice는 **전체 건강도 점수 계산과 분리된 참고 분석**입니다.

즉, Notice 결과가 전체 건강도 점수를 직접 바꾸지는 않습니다.

---

## 10. Notice 비교 기준 데이터

Notice는 다음 두 종류의 데이터를 함께 사용합니다.

```txt
1. 합성 학습 데이터
2. 현재 플랫폼에 등록된 실제 다른 동아리의 상세 지표 데이터
```

현재 분석 중인 동아리는 비교 기준에서 제외됩니다.

또한 실제 다른 동아리 중 사용 가능한 feature 수가 너무 적은 동아리는 비교 기준에서 제외됩니다.

---

## 11. Notice feature 목록

Notice 비교에 사용하는 주요 feature는 다음과 같습니다.

| feature                      | 화면 표시명            |
| ---------------------------- | -----------------------|
| `activeMemberRate`           | 활동 회원 비율          |
| `memberActivityScoreAverage` | 회원 활동 점수 평균     |
| `scheduleSatisfactionScore`  | 활동/일정 만족도        |
| `scheduleActivityRate`       | 일정 활동 인원 비율     |
| `actualAttendanceRate`       | 신청자 대비 실제 출석률 |
| `scheduleStabilityRate`      | 일정 운영 안정성        |
| `paymentRate`                | 회비 납부율             |
| `proofAttachmentRate`        | 증빙자료 첨부율         |
| `feeSatisfactionScore`       | 회비 사용 만족도        |
| `responseRate`               | 만족도 응답률           |

데이터가 없는 feature는 0점으로 처리하지 않고 비교에서 제외합니다.

---

## 12. Notice 계산 방식

Notice는 각 feature의 z-score를 계산하여 현재 동아리의 지표가 비교 평균에서 얼마나 벗어났는지 확인합니다.

```txt
z-score = (현재 동아리 feature 값 - 비교 기준 평균) / 비교 기준 표준편차
```

현재 기준은 다음과 같습니다.

|                 기준 | 의미                        |
| -------------------: | --------------------------- |
|       z-score >= 2.0 | 비교 평균보다 높은 강점 지표  |
|      z-score <= -2.0 | 비교 평균보다 낮은 보완 지표  |
| -2.0 < z-score < 2.0 | 비교 기준 범위 안의 일반 지표 |

표준편차가 너무 작아 z-score가 과도하게 커지는 것을 막기 위해 최소 표준편차 보정값을 사용합니다.

---

## 13. 최종 평가 코멘트

최종 평가 코멘트는 전체 건강도 점수, 영역별 점수, Notice 결과를 종합하여 사용자가 바로 읽을 수 있는 문장형 해석을 제공합니다.

최종 평가 코멘트는 건강도 점수를 새로 계산하지 않고, 이미 계산된 전체 건강도 점수와 Notice 결과를 해석하는 역할을 합니다.

---

## 14. 건강도 랭킹

메인 페이지에서는 전체 동아리의 건강도 랭킹을 조회할 수 있습니다.

랭킹은 각 동아리의 전체 건강도 점수를 기준으로 정렬됩니다.

동점인 경우에는 동아리 이름 기준으로 정렬됩니다.

---

## 15. 관련 파일

건강도 분석과 관련된 주요 파일은 다음과 같습니다.

```txt
clubs/services/health_analysis.py
clubs/services/health_notice.py
clubs/views.py
clubs/data/health_training_data.json
```

| 파일                        | 역할                                       |
| --------------------------- | ------------------------------------------ |
| `health_analysis.py`        | 전체 건강도 점수, 영역별 지표, 최종 응답 생성 |
| `health_notice.py`          | 동아리별 지표 비교 Notice 생성               |
| `clubs/views.py`            | 건강도 분석 API와 건강도 랭킹 API 연결        |
| `health_training_data.json` | Notice 비교에 사용하는 합성 학습 데이터       |

---

## 16. 수정 시 주의사항

건강도 분석 기능을 수정할 때는 다음 사항을 확인해야 합니다.

* 전체 건강도 점수 계산식 변경 여부
* 영역별 점수 계산식 변경 여부
* Notice 비교 방식 변경 여부
* 데이터가 없는 영역을 0점 처리하고 있지 않은지 여부
* 기존 API 응답 구조가 깨지지 않는지 여부
* 메인 페이지 건강도 랭킹에 영향이 있는지 여부
* 건강도 분석 페이지에서 기존 카드가 정상 표시되는지 여부

특히 Notice는 전체 건강도 점수와 분리된 참고 분석이므로, Notice 로직을 수정할 때 전체 건강도 점수 계산식이 함께 바뀌지 않도록 주의해야 합니다.
