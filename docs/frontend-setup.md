# Frontend Setup Guide

이 문서는 **Club Management Platform** 프로젝트의 React 프론트엔드 실행 및 설정 방법을 설명합니다.

프론트엔드는 React와 Vite를 기반으로 동작하며, Django 백엔드 API와 통신하여 동아리, 회원, 회비, 일정, 건강도 분석 등의 화면을 제공합니다.

---

## 1. 프론트엔드 실행 전 준비사항

프론트엔드를 실행하기 전에 아래 프로그램이 설치되어 있어야 합니다.

* Node.js
* npm
* Git

---

## 2. 프론트엔드 폴더 이동

프론트엔드 코드는 프로젝트 루트의 `frontend/` 폴더 안에 있습니다.

---

## 3. npm 패키지 설치

프론트엔드 실행에 필요한 패키지를 설치합니다.

```bash
npm install
```

설치가 완료되면 `frontend/node_modules/` 폴더가 생성됩니다.

* `node_modules/` 폴더는 GitHub에 업로드하지 않습니다.

---

## 4. 개발 서버 실행

프론트엔드 개발 서버를 실행합니다.

```bash
npm run dev
```

정상적으로 실행되면 터미널에 Vite 개발 서버 주소가 출력됩니다.

기본 접속 주소는 다음과 같습니다.

```txt
http://localhost:5173/
```

브라우저에서 위 주소로 접속하여 프론트엔드 화면이 정상적으로 표시되는지 확인합니다.

---

## 5. 백엔드 서버 실행 필요

프론트엔드의 많은 기능은 Django 백엔드 API와 통신하여 동작합니다.

따라서 로그인, 회원가입, 동아리 조회, 가입 신청, 회비 관리, 일정 관리, 건강도 분석 기능을 정상적으로 확인하려면 백엔드 서버도 함께 실행해야 합니다.

백엔드 실행 방법은 `docs/backend-setup.md` 문서를 참고합니다.

---

## 6. 주요 사용 패키지

프론트엔드는 다음과 같은 주요 패키지를 사용합니다.

| 패키지           |   역할                         |
| ---------------- | -------------------            |
| React            | 사용자 인터페이스 구성           |
| React DOM        | React 컴포넌트 렌더링            |
| React Router DOM | 페이지 라우팅                    |
| Vite             | 프론트엔드 개발 서버 및 빌드 도구 |
| lucide-react     | 아이콘 컴포넌트                  |
| react-dropzone   | 파일 업로드 드래그 앤 드롭 처리   |

---

## 7. 프론트엔드 주요 폴더 구조

일반적인 프론트엔드 구조는 다음과 같습니다.

```txt
frontend/
├── public/                 # 정적 파일
├── src/                    # React 소스 코드
│   ├── api/                # 백엔드 API 호출 함수
│   ├── components/         # 재사용 가능한 컴포넌트
│   ├── pages/              # 페이지 단위 컴포넌트
│   ├── App.jsx             # 라우팅 및 전체 앱 구조
│   └── main.jsx            # React 앱 진입점
├── package.json            # npm 패키지 및 실행 스크립트
├── vite.config.js          # Vite 설정
└── index.html              # HTML 진입 파일
```
---

## 8. 프론트엔드 작업 후 확인사항

프론트엔드 코드를 수정한 경우 PR을 생성하기 전에 아래 항목을 확인합니다.

확인할 내용:

* 화면이 정상적으로 렌더링되는지 확인
* 브라우저 콘솔에 오류가 없는지 확인
* 버튼, 링크, 페이지 이동이 정상 동작하는지 확인
* 백엔드 API 요청이 정상적으로 처리되는지 확인
* 기존 기능에 영향이 없는지 확인
* 빌드가 정상적으로 완료되는지 확인

---

## 9. 주의사항

* `frontend/node_modules/` 폴더는 GitHub에 업로드하지 않습니다.
* `frontend/dist/` 폴더는 GitHub에 업로드하지 않습니다.
* 프론트엔드 기능을 테스트할 때는 백엔드 서버도 함께 실행합니다.
* PR 생성 전 빌드 오류가 없는지 확인합니다.
